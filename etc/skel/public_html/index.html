Getting Started

This is a simple template to help you get started with your website. It sets some modern defaults for the HTML rendering right up front:


<!DOCTYPE html>
<html lang="en">
	<head>
		<meta charset="utf-8">
		<meta name="viewport" content="width=device-width">
		<meta name="color-scheme" content="light dark">
		<link rel="stylesheet" href="//gingras.family/css/pico.classless.min.css">
		<title>Getting Started</title>
	</head>
	<body>
		<header>
			<a href="/">← Back</a>
			<h1>Getting Started</h1>
		</header>
		<main>

Let's break this down:

  1. <!DOCTYPE html> Instructs the browser this is an HTML document.
  2. <html lang="en"> Begins the HTML document and sets the language to English.
  3. <head> Begins the "head" section of the document. This contains various metadata, nothing here gets displayed on the page.
  4. <meta charset="utf-8"> Indicates the document uses the "UTF-8" charset, a.k.a. Unicode, a.k.a. allows us to display emojis.☺️
  5. <meta name="viewport" content="width=device-width"> Sets the viewport equal to the device width. Mostly used to make mobile devices display correctly.
  6. <meta name="color-scheme" content="light dark"> Sets the colorscheme for CSS to prefer light unless the user's device requests dark. This page actually supports both and because of this is able to switch based on your own preference.
  7. <link rel="stylesheet" href="//gingras.family/css/pico.classless.min.css"> Pico is a lightweight CSS framework. The main homepage uses it so the href starting with the //gingras.family/ makes this page use the main one hosted there rather than having to copy it into your own home directory. If you did that all you'd have to do is remove that first //gingras.family/ to begin using your own so it would look like href="/css/pico.classless.min.css". Feel free to change to a different CSS framework or even write your own!
  8. <title>Getting Started</title> This isn't the "Getting Started" you see at the top of this page. This sets the text you see on the tab in your browser. They just so happen to be the same thing here.
  9. </head> This ends the head section and with it all the document's metadata.
  10. <body> This begins the "body" section of the document, a.k.a., everything you see on the screen right now.
  11. <header> This denotes a "header" section. There's nothing really special about it, we have it here for semantic reasons.
  12. <a href="//gingras.family/">← Back</a> This is just a convenience. You can also use the browser's back button, but if you navigated here from elsewhere, this takes you back to the site's main page.
  13. <h1>Getting Started</h1> Unlike the <title> above, this is the "Getting Started" you see here. Changing this won't change the browser tab name though, you also have to change it up in the "head" section.
  14. </header> This ends our header section.
  15. <main> This begins the main section. Main is similar to header, its a semantic destinction. Pico CSS uses them to help draw this content, but your perfectly free to remove them and see how it changes.

If I kept going we'd get stuck going in a loop. I hope you understand now the majority of what this does. You can always learn more about HTML, CSS, and maybe even start learning Javascript by reading Mozilla's Developer Documentation. You can also ignore all of this and use a static site generator, a React SPA, PHP, CGI, or any other way you want to design your site.
